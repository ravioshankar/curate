# Icon Generation Script

## Overview
This script generates all required icon sizes for the Curate app across iOS, Android, and Web platforms.

## Usage
```bash
npm install canvas
npm run generate-icons
```

## Generated Icons

### Main Icons (assets/images/)
- `icon.png` (1024x1024) - Main app icon
- `adaptive-icon.png` (1024x1024) - Android adaptive icon
- `splash-icon.png` (400x400) - Splash screen icon
- `favicon.png` (32x32) - Web favicon

### iOS Icons (assets/images/ios/)
- 20px, 29px, 40px, 58px, 60px, 80px, 87px, 120px, 180px, 1024px

### Android Icons (assets/images/android/)
- 36px, 48px, 72px, 96px, 144px, 192px, 512px

### Web Icons (assets/images/web/)
- 16px, 32px, 96px, 192px, 512px

## Design Specifications
- **Background**: Ruby Red (#B91C1C)
- **Diamond**: White geometric diamond shape
- **Text**: White "C" letter below diamond
- **Style**: Minimalist, premium luxury feel
